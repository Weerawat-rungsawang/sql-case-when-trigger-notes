## ฟีเจอร์

- สลับโหมดสว่าง/มืด (จำค่าไว้ในเครื่อง)
- แถบความคืบหน้าการอ่าน + สารบัญไฮไลต์ตามหัวข้อที่อ่าน
- ปุ่มคัดลอกโค้ด SQL ทุกบล็อก (มี syntax highlight)
- เฉลยซ่อนไว้ เปิด/ปิดทีละข้อหรือทั้งหมด
- Quiz 12 ข้อ ตรวจคำตอบและอธิบายเฉลย
- ปุ่มพิมพ์ / บันทึกเป็น PDF (print stylesheet จัดหน้าให้อัตโนมัติ)
- Responsive รองรับมือถือ
